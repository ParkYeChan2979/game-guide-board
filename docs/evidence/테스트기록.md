## 알려진 문제·미실행

- 화면에서 만료 후 글 등록 시도는 수행하지 않았습니다(선택 항목). 변경 API의 만료 처리는 curl(T10)로 확인했습니다.
- 브라우저 개발자 도구의 기기 모드(Responsive)가 켜진 상태로 일부 캡처를 찍어, 요청 헤더의 User-Agent가 Android로 표시됩니다. 실제 실행은 macOS의 Chrome 154입니다.
- 브라우저 캐시 때문에 처음 목록 요청이 304로 표시되어, Network의 Disable cache를 켜고 다시 확인했습니다(서버 응답은 200).
